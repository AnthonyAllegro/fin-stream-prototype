# Inter Finance Explorer

Crie um protótipo web navegável, exclusivamente como referência de design e fluxo (sem processamento real nem persistência), para uma Suíte Financeira desktop que será portada depois para Tkinter. Implemente o briefing completo do usuário: sidebar fixa com todos os módulos, dashboard e telas funcionais para cada funcionalidade; identidade Inter, azul #1B4E8C, cinza #A3A3A3, texto #2D3748, fundos branco/#F7F8FA, sem gradientes ou imagens decorativas. Em todo módulo de arquivos, demonstre de forma navegável o fluxo obrigatório seleção de pasta/drag-drop e contagem elegível → pré-visualização com erros explicados → aviso de backup visível → confirmação específica por quantidade → log com timestamps e resumo final. Use mock data realistas em português. Inclua particularidades descritas para renomear por valor, sequenciador, remoção de prefixos, desbloqueio com senhas, mesclagem NF primeiro, organizar páginas por miniaturas/arrastar/rotacionar/excluir, e separar holerites com revisão manual. Use React/Tailwind/shadcn/lucide; interface limpa, acessível e responsiva, cards discretos borda 1px e raio 8px.
